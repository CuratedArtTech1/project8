# CCG Email Manager - Quick Start Guide

## 🚀 What's Included

The CCG Email Manager is a secure, production-ready Python module for managing emails via IMAP and SMTP. It's designed specifically for the CCG Art Loan System.

## ⚡ Quick Setup (5 minutes)

### Step 1: Set Up Gmail App Password

1. Go to your Google Account: https://myaccount.google.com/
2. Navigate to **Security** → **2-Step Verification** (enable if not already)
3. Go to **Security** → **App passwords**
4. Generate a new app password for "Mail" on "Other (Custom name)"
5. Name it "CCG Email Manager" and click **Generate**
6. Copy the 16-character password (e.g., `abcd efgh ijkl mnop`)

### Step 2: Configure Credentials

The `.streamlit/secrets.toml` file already exists with template values:

```toml
EMAIL = "meghan@ccg-art.com"
EMAIL_PASSWORD = "your_app_specific_password"
IMAP_SERVER = "imap.gmail.com"
IMAP_PORT = 993
```

**Action Required:** Replace `your_app_specific_password` with your Gmail app password from Step 1.

⚠️ **Security Note:** This file is gitignored and will never be committed to the repository.

### Step 3: Install Dependencies (Optional)

```bash
# Install Streamlit for secrets management (optional)
pip install streamlit

# OR install all development dependencies
pip install -r requirements-email-manager.txt
```

**Note:** The email manager uses Python standard library for core functionality, so Streamlit is optional.

### Step 4: Test the Installation

```bash
# Run the example script
python example_email_manager_usage.py
```

Expected output:
- List of email folders
- Recent emails from INBOX
- Unread email count
- Search results
- Send email example (commented out)

## 💻 Basic Usage

### Fetch Recent Emails

```python
from ccg_email_manager_secure import CCGEmailManager, EmailConfig

config = EmailConfig(
    email="meghan@ccg-art.com",
    password="your_app_password",
    imap_server="imap.gmail.com",
    imap_port=993
)

with CCGEmailManager(config) as manager:
    emails = manager.fetch_emails(limit=10)
    for email in emails:
        print(f"{email.sender}: {email.subject}")
```

### Send an Email

```python
with CCGEmailManager(config) as manager:
    success = manager.send_email(
        to_address="client@example.com",
        subject="Loan Statement - October 2025",
        body="Please find your monthly loan statement attached.",
        html_body="<h2>Monthly Statement</h2><p>Statement attached.</p>",
        attachments=[("statement.pdf", pdf_bytes)]
    )
```

### Search Emails

```python
with CCGEmailManager(config) as manager:
    # Find emails from a specific sender
    emails = manager.search_emails('FROM "borrower@example.com"')
    
    # Find unread emails with specific subject
    emails = manager.search_emails('UNSEEN SUBJECT "loan"')
    
    # Find emails from last week
    emails = manager.search_emails('SINCE 21-Oct-2025')
```

## 🔐 Security Best Practices

✅ **DO:**
- Use Gmail app-specific passwords (never your main password)
- Keep `.streamlit/secrets.toml` in `.gitignore`
- Rotate passwords periodically
- Use read-only mode when fetching (default behavior)
- Review logs for unauthorized access attempts

❌ **DON'T:**
- Commit secrets to version control
- Share app passwords via email or chat
- Use the same password across systems
- Disable SSL/TLS verification
- Log sensitive email content

## 🆘 Troubleshooting

### "Authentication failed"
- Verify you're using an app password, not your Gmail password
- Check 2-Step Verification is enabled
- Regenerate app password if needed

### "Connection timeout"
- Check IMAP server and port (imap.gmail.com:993)
- Verify firewall allows IMAP/SMTP connections
- Try with a different network

### "No emails found"
- Verify the folder name (use `list_folders()`)
- Check search criteria syntax
- Ensure emails exist in the specified folder

### "Send failed"
- Verify SMTP settings (smtp.gmail.com:587)
- Check recipient email address format
- Review attachment sizes (Gmail has 25MB limit)
